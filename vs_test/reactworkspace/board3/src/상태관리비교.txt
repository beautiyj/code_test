[상태 관리 방식 비교]

■ 첫 번째 방식 (개별 useState)
- 코드 길이: 입력 항목이 늘어날수록 useState와 onChange 코드가 무한정 길어짐.
- 유지보수: 새로운 항목(예: 비밀번호, 첨부파일) 추가 시 수정할 곳이 많아 번거로움.
- 서버 전송: 전송할 때 { writer, title, content }처럼 변수를 다시 묶어줘야 함.

■ 두 번째 방식 (객체 useState & handleChange)
- 코드 길이: 항목이 10개가 되어도 handleChange 함수 하나로 전부 처리 가능.
- 유지보수: useState 객체에 초기값만 하나 추가하고 name 속성만 맞추면 끝남.
- 서버 전송: 이미 form(또는 formData) 자체가 하나의 객체로 묶여 있어서 그대로 전송하면 되어 편리함.
